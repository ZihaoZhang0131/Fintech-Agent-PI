# 其他细分主题



以下接口来自固定的 AKShare 1.18.83 官方数据字典。读取本文件后，再使用 `scripts/aktools_get.py` 调用。



### repo_rate_hist
- **文档定位**：回购定盘利率-历史
- **HTTP**：`GET /api/public/repo_rate_hist`
- **调用**：运行 `scripts/aktools_get.py repo_rate_hist --param key=value`；参数以本卡的输入参数表为准。

目标地址: https://www.chinamoney.com.cn/chinese/bkfrr/

描述: 回购定盘利率数据

限量: 单次返回指定日期间(一年)的所有历史数据

输入参数

| 名称         | 类型  | 描述                                     |
|------------|-----|----------------------------------------|
| start_date | str | start_date="20200930"; 开始时间与结束时间需要在一年内 |
| end_date   | str | end_date="20201029"; 开始时间与结束时间需要在一年内   |

输出参数

| 名称     | 类型      | 描述      |
|--------|---------|---------|
| date   | object  | -       |
| FR001  | float64 | 注意单位: % |
| FR007  | float64 | 注意单位: % |
| FR014  | float64 | 注意单位: % |
| FDR001 | float64 | 注意单位: % |
| FDR007 | float64 | 注意单位: % |
| FDR014 | float64 | 注意单位: % |

### repo_rate_query
- **文档定位**：回购定盘利率-近期
- **HTTP**：`GET /api/public/repo_rate_query`
- **调用**：运行 `scripts/aktools_get.py repo_rate_query --param key=value`；参数以本卡的输入参数表为准。

目标地址: https://www.chinamoney.com.cn/chinese/bkfrr/

描述: 回购定盘利率数据

限量: 单次返回指定 symbol 的近期数据

输入参数

| 名称     | 类型  | 描述                                                 |
|--------|-----|----------------------------------------------------|
| symbol | str | symbol="回购定盘利率"; choice of {"回购定盘利率", "银银间回购定盘利率"} |

输出参数

| 名称     | 类型      | 描述      |
|--------|---------|---------|
| date   | object  | -       |
| FR001  | float64 | 注意单位: % |
| FR007  | float64 | 注意单位: % |
| FR014  | float64 | 注意单位: % |
