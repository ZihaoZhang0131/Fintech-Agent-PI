# 德国宏观



以下接口来自固定的 AKShare 1.18.83 官方数据字典。读取本文件后，再使用 `scripts/aktools_get.py` 调用。



### macro_germany_ifo
- **文档定位**：德国宏观 / IFO商业景气指数
- **HTTP**：`GET /api/public/macro_germany_ifo`
- **调用**：运行 `scripts/aktools_get.py macro_germany_ifo --param key=value`；参数以本卡的输入参数表为准。

目标地址: https://data.eastmoney.com/cjsj/foreign_1_0.html

描述: 东方财富-数据中心-经济数据一览-IFO商业景气指数

限量: 单次返回所有历史数据

输入参数

| 名称  | 类型  | 描述  |
|-----|-----|-----|
| -   | -   | -   |

输出参数

| 名称   | 类型      | 描述  |
|------|---------|-----|
| 时间   | object  | -   |
| 前值   | float64 | -   |
| 现值   | float64 | -   |
| 发布日期 | object  | -   |
