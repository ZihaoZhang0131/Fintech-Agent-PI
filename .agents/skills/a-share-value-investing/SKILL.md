# A 股质量价值投资

执行研究时必须完成“全市场筛选 → 30 只深挖 → 官方证据核验 → 最多 10 只结论”，不得只凭单期估值、新闻或模型常识给股票。

## 1. 准备与口径

1. 明确截止日；用户未指定时使用运行当天。默认覆盖沪深京 A 股，排除银行、证券、保险和多元金融。
2. 调用 `load_skill` 加载 `akshare-http-data`。按其说明先运行状态脚本，再读取 `references/stock/index.md` 和所需接口卡；不要猜测接口名、参数或字段。
3. 调用 `read_skill_resource` 读取本 Skill 的 `references/methodology.md` 和 `references/data-contract.md`。严格使用其中的评分、硬性排除、数据充足度和错误处理规则。
4. AKTools 不可用时停止结构化筛选，向用户说明启动方法；不得自行启动后台服务，也不得用网页零散数据假装完成全市场筛选。

## 2. 全市场初筛

运行：

```text
name: "a-share-value-investing"
path: "scripts/screen_candidates.py"
args: ["--as-of", "YYYY-MM-DD", "--deep-count", "30"]
timeoutSeconds: 120
```

只接受脚本返回的 `candidates` 作为深挖池。记录报告期、实际接口、覆盖率、排除统计、缺失字段和每项分数。核心接口失败或 `usable_for_research=false` 时停止给出股票。

## 3. 深挖 30 只候选

从初筛结果复制股票代码，最多 30 只，运行：

```text
name: "a-share-value-investing"
path: "scripts/deep_metrics.py"
args: ["--as-of", "YYYY-MM-DD", "--symbols", "600519,000858,..."]
timeoutSeconds: 120
```

按代码合并两次脚本输出。用深挖结果的估值支持数替换初筛估值分：0 项为 0 分、1 项为 8 分、2 项为 16 分、3 项为 20 分，再重新计算总分。总分不足 70、估值支持少于 2 项或存在硬性排除项的股票只能进入观察名单。

不得把空数组解释为没有商誉、质押、公告或风险。接口失败、字段漂移、覆盖不足都必须保留为 `missing_fields` 或待核验事项。

## 4. 逐只补全业务和一手证据

对重新排序后的候选逐只核验，直到得到最多 10 只合格股票或候选耗尽：

1. 通过 `akshare-http-data` 获取主营构成、个股公告、最新行情和必要的历史数据。结构化接口用于发现线索，不代替公告正文。
2. 使用 `web_search` 查找巨潮资讯、上交所、深交所、北交所或公司官网的最新年度报告、最新已披露定期报告以及最近 24 个月风险公告。每只最终股票至少保留两份可点击的一手资料及发布日期。
3. 核验商业模式、收入来源、竞争优势是否能由报告事实支持；明确区分事实、推断和待验证事项。
4. 检查非标审计意见、监管立案、财务真实性、重大诉讼担保、控股股东高比例质押、商誉减值和持续融资稀释。未解决的硬性风险直接移入观察名单。
5. 研报和新闻只能作为线索或反方材料；不得把目标价、评级或媒体转述当作推荐理由。

如果已配置专业 Agent，可把结构化数据核对或官方网页证据搜索分别委派给对应角色；未配置或回传不完整时由主 Agent继续完成，不得声称已经委派或核验。

## 5. 输出

先说明截止日、股票池、使用的报告期和接口、排除数量与数据限制。随后输出：

1. 最多 10 只股票总表：代码、名称、行业、总分、估值支持项、置信度和一句话理由。
2. 每只股票的商业质量、五年财务证据、现金实现、资产负债、估值理由、股东回报、两份以上官方来源、反方证据、主要风险和失效条件。
3. 观察名单：说明未入选原因、缺失证据或需要等待的价格/报告。

最终数量可以少于 10，只在全部门槛都满足时列入正式候选。启用了 `write_project_file` 时，把完整报告保存为 `outputs/a-share-value-investing-YYYYMMDD.md`；否则在聊天中给出完整报告。结尾注明“仅供研究参考，不构成投资建议”。
